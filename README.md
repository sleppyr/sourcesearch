# SourceSearch

Бот для поиска свободных Telegram-юзернеймов: быстрый поиск, ультра-ники, оценка, трекер, бонусы, розыгрыши, админка.

## Запуск
1. `pip install -r requirements.txt`
2. В `.env` вставь `BOT_TOKEN` (от @BotFather).
3. `python login.py` — один раз войди **обычным аккаунтом по номеру телефона** (не токеном бота!).
4. `python bot.py`

## Как ускорить поиск
Каждый воркер работает параллельно, скорость растёт почти линейно:
- `python login.py acc2` и в `.env`: `SESSIONS=sourcesearch,acc2` — ещё аккаунты-проверяльщики;
- `RESOLVER_BOTS=токен1,токен2` — доп. боты (создай в @BotFather): они мгновенно отсеивают занятые ники;
- основной бот уже работает резолвером (`USE_MAIN_BOT_AS_RESOLVER=1`).
Статус воркеров: Админка → «Воркеры».

Двухступенчатая проверка: `resolveUsername` (быстро, боты и аккаунты) → `checkUsername` (точное подтверждение, аккаунты).

## Файлы
- `bot.py` — бот, `pool.py` — пул проверки, `core.py` — БД/генератор/оценка, `ui.py` — оформление
- `login.py` — вход аккаунтов, `make_banner.py` — перегенерация `banner.jpg`
- `words.txt` (необязательно) — свой словарь для ультра-поиска, по слову в строке

## Админ
`/admin` или кнопка «Админка»: статистика, воркеры, Premium, алмазы, инфо о юзере, бан/разбан, промокоды, розыгрыши, рассылка.
Админ пользуется ботом бесплатно и без лимитов.

Не публикуй `.env` и файлы `*.session`.

## Railway
См. подробную инструкцию в чате: репозиторий GitHub (без `.env`) → New Project → Deploy from GitHub →
переменные `BOT_TOKEN, API_ID, API_HASH, ADMIN_IDS, STRING_SESSIONS, DB_PATH=/data/sourcesearch.db` → Volume на `/data`.
Строку сессии для `STRING_SESSIONS` получи локально: `python login.py --string`.
